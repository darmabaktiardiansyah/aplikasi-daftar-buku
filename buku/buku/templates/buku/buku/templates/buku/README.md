# Aplikasi Daftar Buku

Aplikasi web sederhana menggunakan Django untuk menampilkan daftar buku dan detail buku.

## Fitur
- Menampilkan daftar buku.
- Melihat detail buku.
- Kembali ke halaman daftar buku.

## Teknologi
- Python
- Django
- HTML

## Cara Menjalankan
1. Install Django.
2. Jalankan perintah python manage.py runserver.
3. Buka http://127.0.0.1:8000/buku
